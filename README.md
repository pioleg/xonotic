# Config files for Xonotic

## Installation

Put files into:

| System   | Path                               |
| -------- | ---------------------------------- |
| Windowxs | %USERPROFILE%\Saved Games\xonotic\ |
| Linux    | $HOME/.xonotic/data/               |

`autoexec/first-time-setup.cfg` will be executed only on next game start (further starts are prevented by custom variable `first_setup_done `).
